📊 Dev Books Dashboard

The Dev Books Dashboard provides clear insights into book sales, customer behavior, and revenue trends. It helps businesses make data-driven decisions by identifying patterns in sales performance and customer engagement.

Using Power BI and Excel, the dashboard integrates data from multiple sources to visualize key metrics such as total revenue, order trends, and customer distribution.

Technologies Used: Power BI, Excel

Category: Data Analysis & Visualization
